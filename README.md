# CupSir Macro Dashboard — Starter Pack

A static market-research dashboard published with GitHub Pages and updated by GitHub Actions.

## What is included

- Future two-week event calendar
- Market-news panel (sample data; replace with your news source)
- Left-hand indicator list and interactive detail panel
- CupSir-style checks for eight MVP indicators
- Generated research summary panel
- GitHub Actions workflows for data refresh and GitHub Pages deployment

## Important

This is a research dashboard, not trading software or financial advice. Verify all data before relying on it.

See **USER_GUIDE.md** for full installation instructions.
